# 📊 AdventureWorks End-to-End Data Analytics Project

This is a complete End-to-End Data Analytics project using the **AdventureWorks** dataset (CSV format).  
The project focuses on data cleaning, transformation, modeling, visualization, and business insights for sales and customer performance.

---

## ✅ Project Highlights

✅ Fully end-to-end pipeline (Data → ETL → Analytics → Insights)  
✅ Works completely on CSV files (no SQL Server required)  
✅ Clean, structured data processing  
✅ Exploratory Data Analysis (Sales, Products, Geography, Customers)  
✅ KPI tracking and dashboard creation  
✅ Suitable for real-world portfolio / interviews

---

## 📁 Dataset Used

- AdventureWorks Sales CSV files (e.g.)  
  - Customers.csv  
  - Products.csv  
  - Sales.csv  
  - Geography.csv  
  - Calendar.csv

## ✅ Steps Performed (End-to-End)

### 1️⃣ Data Import
- Loaded all CSV files (Customers, Sales, Products, Geography, etc.)
- Merged dataset to create a complete fact table

### 2️⃣ Data Cleaning
- Handled missing values
- Standardized date formats
- Removed duplicates
- Fixed inconsistent columns

### 3️⃣ Data Transformation
- Added calculated fields:
  ✅ Total Sales  
  ✅ Profit  
  ✅ Revenue Per Customer  
  ✅ Year / Quarter / Month columns

### 4️⃣ Exploratory Data Analysis
- Top-selling products
- Best performing regions
- Most profitable customers
- Seasonal sales trends
- Year-over-Year comparison

### 5️⃣ Insights & Visualizations
Created Power BI / Tableau dashboard showing:
✅ Total Sales  
✅ Profit  
✅ Region-wise performance  
✅ Customer segmentation  
✅ Category-wise revenue
